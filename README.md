## 如何打開編輯後台
1. 打開瀏覽器。
2. 到這個網址：`https://app.pagescms.org`。
3. 點選「使用 GitHub 登入」。
4. 輸入你的 GitHub 帳號密碼。
5. 登入後，找到這個網站的專案名稱。
6. 點一下專案名稱，進入後台。

## 如何新增文章

進入後台後，左側選單會看到「文章」。

點進去可以看到目前所有文章。

### 新增文章步驟

1. 點選左側「文章」。
2. 點右上角「新增」按鈕。
3. 在「標題」欄位輸入文章標題。
4. 在「網址」欄位輸入英文網址。
5. 在「摘要」欄位輸入一小段文章介紹。
6. 選擇「封面圖片」（可略過不選）。
7. 選擇「發佈日期」。
8. 在「內容」欄位輸入文章內容。
9. 確認「草稿」是否勾選。
10. 按下「儲存」。

> ⚠️ 注意
> 「網址」欄位發佈後請不要更改。
> 改了網址，舊的連結會打不開。

> 💡 小提醒
> 「草稿」打勾，文章不會出現在文章列表。
> 但知道網址的人，還是可以直接看到內容。
> 如果要正式公開，記得把「草稿」取消勾選。

### 修改已經發布的文章

1. 點選左側「文章」。
2. 在列表中找到要修改的文章。
3. 點一下文章標題。
4. 修改需要更動的欄位。
5. 按下「儲存」。

### 完成後請確認

- 已按下儲存。
- 沒有出現錯誤訊息。
- 「草稿」的勾選狀態是你要的狀態。
- 文章內容正確無誤。

## 如何修改頁面

除了文章，網站還有幾個固定頁面可以修改。

目前開放編輯的頁面有：

- 關於頁面
- 隱私權政策
- 服務條款
- 網站設定（網站名稱、簡介、作者資訊、社群連結等）

> 💡 小提醒
> 首頁最上方的大標題文字，不屬於這裡可以編輯的範圍。
> 如果要修改，請找當初架設網站的人幫忙。

### 修改文字步驟

1. 點選左側選單。
2. 找到要修改的頁面。
3. 點一下頁面名稱。
4. 修改文字。
5. 按下「儲存」。

> ⚠️ 注意
> 不要關閉網頁後才發現沒有按「儲存」。

### 修改網站設定步驟

「網站設定」裡可以修改：

- 網站名稱
- 網站描述
- 作者姓名與簡介
- Instagram、Threads、YouTube 連結
- 首頁要顯示幾篇最新文章

1. 點選左側「網站設定」。
2. 找到要修改的欄位。
3. 修改內容。
4. 按下「儲存」。

### 完成後請確認

- 已按下儲存。
- 沒有出現錯誤訊息。
- 頁面內容正確更新。

---

### 發布步驟

1. 完成內容修改。
2. 檢查一次內容有沒有打錯字。
3. 按下「儲存」。
4. 稍微等待幾分鐘。

> 💡 小提醒
> 按下儲存後，網站不會馬上變。
> 網站背後需要一點時間重新整理內容。
> 通常幾分鐘內就會完成。

### 完成後請確認

- 已按下儲存。
- 沒有出現錯誤訊息。
- 已經稍微等待幾分鐘。

## 如何確認網站已更新

儲存完之後，建議實際去網站確認一次。

### 確認步驟

1. 打開瀏覽器。
2. 輸入你的網站網址。
3. 等網頁完全打開。
4. 用力重新整理網頁一次。
5. 檢查修改的內容是否出現。

> 💡 小提醒
> 「用力重新整理」是指同時按 Ctrl 和 F5。
> 這樣可以避免看到舊的畫面。

> 💡 小提醒
> 請把上面的「你的網站網址」換成自己網站的實際網址。
> 這份文件沒辦法幫你填上正確網址。

### 完成後請確認

- 網頁可以正常打開。
- 修改的文字或圖片都有出現。
- 沒有看到舊的內容。

## 如何讓網站更容易被 Google 找到

### 頁面標題怎麼寫

1. 標題要簡短。
2. 標題要說明這頁在講什麼。
3. 標題放最重要的字在前面。

範例：

> 好的標題：夏日海邊穿搭建議
> 不好的標題：分享、心得、大家一起來看看

### 文章標題怎麼寫

1. 一篇文章只寫一個主題。
2. 標題要讓人一看就懂內容。
3. 不要用太抽象的標題。

範例：

> 好的標題：新手也能學會的番茄炒蛋做法
> 不好的標題：今天的小故事

### 內文怎麼寫

1. 一段文字不要太長。
2. 一段只講一件事。
3. 用簡單的字，不用艱深的詞。
4. 段落之間可以加小標題。

### 圖片檔名怎麼取

1. 用英文或數字命名。
2. 檔名要說明圖片內容。
3. 文字之間用「-」連接。
4. 不要用「圖片1」「IMG001」這種名稱。

範例：

> 好的檔名：ocean-sunset.jpg
> 不好的檔名：IMG_20240101.jpg

### 圖片替代文字（Alt）怎麼填

替代文字，是給看不到圖片的人看的說明文字。

1. 打開圖片設定的地方。
2. 找到「替代文字」或「Alt」欄位。
3. 用一句話說明圖片內容。
4. 不用加「圖片」兩個字。

範例：

> 好的替代文字：夕陽下的海邊
> 不好的替代文字：圖片、IMG、照片1

> 💡 小提醒
> 文章的「封面圖片」欄位，替代文字由系統自動處理。
> 你不需要另外設定。
> 只有在文章內容裡插入圖片時，才需要自己填寫替代文字（如果編輯畫面有出現這個欄位）。

### 一個頁面只講一個主題

1. 一篇文章只圍繞一個主題寫。
2. 不要把很多不相關的內容塞在同一篇。
3. 不同主題，開新的文章來寫。

### 不要重複塞相同的關鍵字

1. 關鍵字自然出現就好。
2. 不要同一句話重複同一個詞。
3. 不要為了塞關鍵字而寫奇怪的句子。

範例：

> 不好的寫法：海邊穿搭、海邊穿搭推薦、海邊穿搭教學、海邊穿搭分享
> 好的寫法：這篇文章分享幾套適合海邊的穿搭。

### 修改網址時要注意什麼

> ⚠️ 注意
> 文章發佈後，請不要修改「網址」欄位。
> 這個網站沒有提供其他頁面的網址修改功能，可略過。

如果真的一定要改：

1. 先確認這篇文章還沒有被分享出去。
2. 修改「網址」欄位。
3. 按下「儲存」。
4. 用新網址再檢查一次文章。

### 完成後怎麼自己檢查

- 標題有沒有清楚說明內容。
- 內文有沒有分段。
- 圖片檔名是不是看得懂意思。
- 圖片有沒有填替代文字。
- 有沒有重複塞很多次同一個詞。
- 有沒有實際打開網頁確認過畫面。

## 常見問題

### 找不到要修改的頁面怎麼辦？

先看左側選單有沒有這個項目。

如果沒有，代表這個網站沒有開放編輯這個頁面，可以略過。

### 修改後網站沒有更新怎麼辦？

1. 先確認有沒有按下「儲存」。
2. 再等幾分鐘。
3. 用力重新整理網頁再看一次。
4. 還是沒更新，請找架設網站的人幫忙檢查。

### 圖片無法上傳怎麼辦？

1. 檢查網路是否正常。
2. 檢查圖片檔案是不是太大。
3. 換成 jpg 或 png 格式再試一次。
4. 還是不行，請找架設網站的人幫忙。

### 圖片太大怎麼辦？

1. 用手機或電腦內建功能，把圖片縮小。
2. 或用線上工具壓縮圖片大小。
3. 壓縮後再重新上傳。

### 不小心刪掉內容怎麼辦？

> ⚠️ 注意
> 按下儲存前，內容改動都還沒有真正生效。

1. 先不要按下「儲存」。
2. 直接關閉這個編輯畫面。
3. 重新打開這篇文章或頁面。
4. 內容應該會恢復到上一次儲存的樣子。

如果已經按下儲存，請看下一題。

### 可以恢復上一個版本嗎？

這個功能要看網站的技術設定，不一定每個網站都能自己操作。

請找架設網站的人幫忙確認與復原。

### 修改錯誤怎麼辦？

1. 重新打開這篇文章或頁面。
2. 把錯誤的地方改回正確內容。
3. 按下「儲存」。
4. 到網站確認內容是否正確。

## 名詞小字典

- **PagesCMS**：這個網站用來編輯內容的後台系統。
- **後台**：用來修改網站內容的管理畫面。
- **CMS**：後台系統的英文說法，全名是內容管理系統。
- **GitHub**：存放網站資料的地方，登入後台需要用到。
- **Git**：一種紀錄網站內容變化的技術，你不需要學會操作。
- **儲存庫（Repository）**：存放這個網站所有檔案的地方。
- **網址欄位（Slug）**：文章專屬的英文網址名稱。
- **草稿（Draft）**：還沒公開、只有知道網址才看得到的內容。
- **Markdown**：一種簡單的排版寫法，用來讓文字有標題、粗體等效果。
- **替代文字（Alt Text）**：說明圖片內容的一小段文字，給看不到圖片的人用。
- **關鍵字**：使用者在 Google 上搜尋時輸入的字詞。
- **快取（Cache）**：瀏覽器暫存的舊畫面，有時要用力重新整理才會更新。
