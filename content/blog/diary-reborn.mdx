Miss you all sooooo much.  
很想跟大家說說話，但眼睛快要闔上了。

想念和玫瑰面談前和渝婷的擁抱，也想念渝婷的提問與提醒。  
:「妳是不是都要碰撞以後，才會放鬆下來 ?」

想去聽聽婉諭的分享會，也聽聽小吉的。  
So weird，年初還是那個跑遍 TFT 分享會，想加入TFT的人。  
現在已經是 TFT 的老師了。

安全帽上貼著 TFT 的貼紙，  
穿 TFT 的衣服去上課，還會被學生問起 : 怎麼會穿這件衣服。

說到這個，我今天被小鷸訪問。  
: 老師，你自我介紹一下。  
: 老師你從哪裡來 ?  
: 你不是有一個組織嗎 ?  
: 你為什麼要來 ?  
: 老師你今天會留下來嗎 ?  
: 老師你為什麼要穿得像男生 ?  
: 老師你覺得你們班的小孩討厭你嗎 ?  
: 那現在呢 ?

小鷸最近叫我都叫全名。  
今天騎車去買熱巧克力的時候想到這件事，突然就想哭。  
想到我對自己相信的老師也是叫名字，這些老師也不避諱讓我直接叫名字。  
挺好的吧，真的挺好的。  
大概是真的把我當朋友了吧。  
我知道這樣的關係裡還有她對我的尊重和服從。

雖然其他年級的小孩也會問起 : 老師，為什麼她叫妳可以直接叫名字 ?

小鷸今天直接跟我搶辦公椅子，我們一人坐一半，一起算數學。  
我們會一起唱歌，一起玩大老二、五子棋。

不知怎麼地，其實挺感動的。  
我們變得好像 … 距離很近。  
這樣的距離，也能讓學習發生，或是讓學習發生得更順利。  
最近我在國語課上的提問，孩子們都熱烈地搶答。  
請孩子說出文章大意時，兩位孩子都可以獨立講出整篇文章發生了什麼。

葉宇嘛，就是老樣子。  
功課不寫，說出來的話兌現不了。  
遇到壓力就開始扮鬼臉，令人討厭的松子的一生裡的松子。  
但我習慣了這孩子很容易在壓力下出現這些反應，能做的就是提醒他逃了幾次，然後等他回來。  
給他一個安全的環境，至少在我的教室裡安全。

最近面對葉宇時，累積了一個我很喜歡我自己的時刻。  
那天葉宇被罵了，是有關性平的案子。  
路過辦公室，看見主任、組長、宜嘉都在處理。  
我還搞不清楚是什麼事。  
小鷸一回教室就告訴我 : 「老師，葉宇好像發生了什麼了不起的大事。」  
在校督導也說 : 「對啊，他好像真的做了什麼大事。」

看著葉宇的抽屜，答應我要交的作業全都留在教室了。  
走去夜光的教室提醒他 : 「孩子，你的作業有帶嗎 ?」  
葉宇沒有回應，一臉大便。  
我就是回教室慢慢收東西，等等看是否和這個孩子有緣。

收好東西正要離開，聽到小鷸對葉宇說 : 「老師還在教室。」  
我把背好的包包放下，筆電安置好，像是還沒有要離開。  
葉宇進到班上，一句話都沒說，就是開始翻抽屜找作業。  
我拿便條紙讓他核對該帶的功課。  
他要離開以前，我說 : 「你要不要跟汪汪說說話 ?」  
葉宇走回來，摸了摸汪汪，不太知道要說什麼。  
我拿著汪汪開口 : 「謝謝你今天中午睡覺的時候幫我蓋被子 ~」  
葉宇 : 「不客氣 ~」  
葉宇看著汪汪，開始和汪汪對話。  
葉宇和汪汪聊了幾句，和汪汪說了掰掰。  
整個人放鬆了不少，臉上掛著微笑，離開了教室。

那天我真的挺喜歡我自己的。  
至少孩子無論在外面犯了什麼錯，回來教室，就算我很擔心，也可以忍住不去問。  
讓孩子舒緩自己的情緒，說說自己想說的，給予自己就算遍體鱗傷，還是想要好好對待世界的溫柔。  
那一間有安全感的教室，輪廓好像就這樣子畫出來了，挺好的。

最近和孩子們的關係都好。  
除了葉宇作業都不寫，要讓他補完作業實在像極了要登月。

每次看到葉宇，我心裡都會陷入某一種兩難。  
葉宇真的是一個挺善良的孩子。  
會讓我忍不住去想，這麼善良，但目前還不太能跟上數學進度的孩子，有什麼樣的可能性。  
善良可以幫助這個孩子什麼嗎 ?  
我其實不太確定。

心裡多少還是不太能跳脫框架，會覺得這個孩子只有善良，以後會如何如何被騙，如何如何無法照顧自己的家人。  
不確定自己是否又把都市人的框架套在了孩子身上。  
不確定孩子一輩子採金針是否會真的快樂。  
葉宇不相信自己可以學會課本習作上的知識，也不覺得自己有學會的必要。畢業後的夢想就是去採金針花存錢，讓阿公阿嬤過好日子。

每次想到這些，多少有一點點沉重。

回到日常生活的話，身為導師的我最近過得挺幸福的，他們兩個孩子在班上應該也是挺開心的。  
我自己變了挺多，這一路走來慢慢就自在了。  
看著自己的課堂錄影，從沒想過自己的課堂樣貌能變成今天這樣。

其實很謝謝他們，也很謝謝自己。  
謝謝我們都沒有放棄彼此，沒有放棄去愛，沒有逃走，選擇留在彼此身邊。

打到這裡，想起 SUNNY 提醒我的 : 「愛沒什麼方法，愛就是方法。」  
突然很想說，我很愛你們。

也想到小鷸幾乎每天都揚言要殺了汪汪，對待汪汪時卻又極其溫柔。  
慢慢也都可以理解了。  
就像我說不出愛這群孩子，說不出會不捨這個即將畢業的班級，偶爾也對他們兇或生氣。  
就像我好像常常要看起來是某一種武裝過的樣子。

小鷸最近拿了畢業紀念冊希望我留言。  
真有什麼要說的話，大概也和給我自己的提醒一致吧。

希望我們可以呈現真實地自己，一致地表達自己。  
脫下武裝，讓自己的外在行為和自己的內心吻合。  
勇敢地承認自己愛這個世界，很愛很愛，所以也很怕很怕受傷。  
然而我們已經一步一步學會勇敢，可以在受了傷以後，依然選擇好好對待這個世界。  
喜歡的就說喜歡，討厭的就說討厭，不再一再傷害在乎自己的人、自己在乎的人。  
讓愛成為讓人舒服的樣子，真實地流露出來。  
練習去愛那個充滿愛，莫名脆弱卻也十足勇敢地自己。

對了，最近又想起野人。  
雙十一看到他的直播吧。  
你說喜歡他的歌嗎，好像也還好。  
但就很欣賞這個人。  
任性地作夢，認真的失敗，但是一再站起來，還是要認真的面對真實的自己，面對不可能實現的夢想，還有自己的信念和堅持。

在一開始和這些孩子關係恢復的時候，聽到野人的歌直接爆哭一波。  
「就抓緊我吧 相信我吧 我是溫柔的 怪物 折斷了利爪 有溫暖的掌 把冰雪都 融化」  
「傷還在流血在失去意識前 請聽我說 我不後悔停留 不後悔我瘋狂愛過」  
「放下了固執 才能穿過黑洞 找到了綠洲 原來一直 在手中」

再來一次，還會不會投履歷，還會不會加入 TFT ?  
前些日子我真的會想，自己到底在這裡幹嘛。  
但總是抓著什麼，抓著什麼不想放。  
原來阿，原來我還是好想好好去愛，雖然完全找不到方向和方法。

三個月後終於可以很驕傲地對自己說，我不後悔停留，不後悔瘋狂愛過。  
我還算蠻喜歡這份工作的，每天工作的時候，除了壓力以外，還可以感受到很多很多幸福。

「謝謝我們都沒有放棄相信 霧散去後 可以看見星星。」
