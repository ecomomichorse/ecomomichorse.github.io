這是一篇 **placeholder（佔位）** 文章，用來示範這個部落格範本的文章排版，包含標題、段落、清單與圖片說明的顯示方式。

## 如何開始

1. 登入 Pages CMS，找到「文章」這個內容類型。
2. 編輯或刪除這篇範例文章。
3. 建立你自己的第一篇文章。

## 支援的格式

- **粗體** 與 *斜體* 文字
- 項目清單
- 標題會自動產生目錄（如果內容夠長）

### 程式碼

行內程式碼像這樣：`npm run dev`，區塊程式碼則像下面這樣：

```ts
function greet(name: string) {
  return `Hello, ${name}!`;
}
```
