最近孩子們在寫作文，題目是 – 一次真心的道歉。  
小鷸和葉宇只要待在一塊，兩個人就很難靜下來，所以今天寫作文時，我把他們倆分開。  
小鷸和我算是挺有默契，小鷸需要我的引導時會喚我。  
通常我會需要給她幾個問題，幫助她在想深一點，或幫助她換句話說，或是引導她，擴寫時可以思考哪些層面。  
通常會問到小鷸說出 : 「哦，我知道了。」  
我會追問 : 「自己可以了 ?」  
也追問 : 「還需要我的幫助嗎 ?」  
小鷸會想一想，和我確認自己沒問題以後，自己想辦法、自己學習。

小鷸可以自己解決問題以後，通常我就會蹲在葉宇的課桌旁邊。  
大多是引導葉宇說出自己想說的話，這部分我還蠻常失敗的。  
葉宇很難真的用文字說出自己的感受，我不太確定葉宇卡在哪，可能是忘記去感受，或是不知道每一種感受對應的文字，該如何精準的表達。  
葉宇還有一個歷史悠久的特徵，他擅長遺忘。

和葉宇上個班導通電話，歷任班導也提了這件事。  
很多事情今天跟葉宇說了，確認他會了，他也答應你他會負責做好了，  
但隔天好像什麼都沒發生一樣，他好像是真的覺得什麼都沒發生，很快就忘記事情。  
許多時候我觀察葉宇，我覺得自己大概可以理解，葉宇為什麼需要快速遺忘的技能。

記得有天我留下葉宇在教室寫作業，那天我去開會。  
經過三個小時回到教室，葉宇的功課還是沒寫完。  
那天我的生氣、難過與失望應該是能被感受到的，但那天晚上我再看見葉宇，他能彷彿沒事一樣，和我說說笑笑，乖乖的寫作業。  
我的心情其實蠻難平復的，我不太知道他怎麼能好這麼快。  
那天是我心裡第一次閃過 : 「啊，難怪他需要忘記。」  
原本只是大概感覺到，葉宇有自己的防衛機制，後來才慢慢發現，遺忘似乎是葉宇的防衛機制。  
面對挫折或痛苦，葉宇也許不是挫折復原力超群，而是善忘。

今天葉宇寫作文，我按照慣例要他想「他想要道歉的事件細節」。  
他也老樣子回答我 : 「老師我忘記了，我真的想不起來。」  
後來小鷸請我去解決個問題，我想說來放點輕音樂。  
放完輕音樂，我蹲回葉宇旁邊，繼續問他 : 「發生什麼事情，你想跟阿嬤道歉 ?」  
葉宇突然幽幽的說 : 「因為阿嬤年紀大了，身體沒有那麼好了，力氣也沒有那麼大，我應該多幫忙阿嬤一點。」  
我繼續問 : 「發生了什麼事情，讓你想到這些 ?」  
葉宇笑了，看著我說 : 「因為現在在放的音樂啊。」  
我覺得葉宇有在認真回答我的問題，不過我實在太想要他把作文的段落生出來，所以我一開始我沒能理解葉宇的意思，我非常疑惑的問他 : 「你原本被阿嬤叫去採竹筍，你很生氣。你氣阿嬤每次都叫你做事情，不叫家裡的其他小孩子，發生了什麼轉折，你想要跟阿嬤道歉 ? 你回答因為現在放的音樂，這樣邏輯不通啊。」  
看了看葉宇的作文，我繼續說 : 「但是沒關係，你這樣寫也可以，雖然原本你很生氣，但是你想到阿嬤年紀大了，所以反省了自己，想跟阿嬤道歉，那下一段你就寫道歉的內容。」  
時間加進度的壓力，當時的我大概很挫折吧。  
這樣的挫折，也讓我錯過了第一時間接住孩子的機會。

幸好，我大概有隱約感覺到自己有夠緊繃。  
下課前問了葉宇 : 「這些事情說出來，你有舒服一點嗎 ?」  
葉宇的表情柔和了許多，開心地回答我 : 「有。我剛剛突然想到，小時候是阿嬤把我帶大的。」

葉宇輕聲地繼續說 :  
「小時候我媽媽就跑去喝酒嘛，  
然後我阿公阿嬤還跑去跪著求我媽媽回來餵我喝奶。  
我剛剛聽這個音樂想到這個。  
我就想到我阿嬤年紀也很大了，  
我應該多幫忙一點，多做一點事。」

看著葉宇，我有些感動，卻還沒代謝掉剛剛指導葉宇的挫折感，我盡力的穩定自己的語氣，緩緩地說出 : 「謝謝你跟我說這些。」

「呼，說出這些輕鬆多了。」葉宇微笑著說。  
我猜，這樣的輕鬆也許掃去了葉宇原先在寫作文時的壓力，葉宇現在整個人微發光呢。  
「老師那我去上課了哦，老師你要休息哦，等下吃飯要自己先去盛哦。」  
葉宇在關上教室的門，移動到下個教室以前，回頭叮嚀我。

看著他走出去的背影，我開啟筆電的記事本，留下這段話 :

「孩子，寫我指派的作文，我不希望你痛苦。  
但文字是我的朋友，我也希望建立你和它交朋友的可能。  
寫我的作文，誠實就好，說你想說的話。  
因為你善良，自然就可以感動其他人，  
做你自己就好。」

-

葉宇的狀況還是起起伏伏。  
唯一不變的大概就是每當他遇到挫折，會需要有個人帶著他度過。  
像是陪著他面對從前選擇遺忘的事，陪著他面對重新學習的困難。  
在他克服這些困難之後告訴他，你可以做到，或是聽他說說他的感受。

雖然這些我大概都還做得到，但是當葉宇在撞牆的時候，  
我還是會被葉宇體現挫折時的反應牽動情緒，  
像是 :  
「我不想寫拉，好難哦。」  
「我最討厭寫作文了。」  
「吼唷 ! 我想不起來，我就是想不起來啦 !」  
搭配上趴在桌上、躺在椅子上、持續伸懶腰、持續用筆敲打桌面發出聲響，此類的動作。

各種行為加話語排列組合後，大概都是我看了心情會不太美妙的 set 。

我還不夠穩定，也還不夠溫柔。  
還不太能夠看見行為的背後，那些受傷與挫折。

寫出這些以後，下次再看見這樣的葉宇，  
我大概更能覺察我自己，更有方法減少自己在陪伴他時的挫折或受傷了吧。
