晚安各位，BLOG 停更的這週我大哭了兩次，照慣例還是去了海邊。  
經歷了跟在校督導的療癒談話，跟玫瑰的卡卡面談，寫寫新買的筆記本療癒自己，再被挫折包圍。

跟玫瑰面談的前一天發生的事情，我休息了一天才把狀況打在面談紀錄裡。  
跟玫瑰面談的那天，我想我還是脆弱。

紀錄如下 :

等等要面談了，我想要把昨天跟在校督導說的話，或是我們今天討論的事情記錄下來。  
我不確定這是否有幫助面談但就做一個記錄。  
我想記錄的是昨天 Bowen邀請宜嘉跟在校督導來家裡吃飯。  
在那之前我把班上教室掃一掃、清一清，把孩子們做自然實驗弄髒的流理台清乾淨。回家掃地拖地，希望給客人一個乾淨的空間。弄完之後，洗個澡，看一下「心靈的傷，身體會記住」。  
看到一半宜嘉先到了，宜嘉有一雙可以經常發現驚喜的眼睛，還有讓快樂變簡單的靈魂。宜嘉在房間和客廳裡東看看，西看看，走來走去的。接著在校督導也來了，Bowen原先想進入我班經上遇到的問題，在校督導請我們吃完飯再說。吃完咖哩飯、牧羊人派，還有甜點以後，我被 cue 到要說說自己昨天跟學生的衝突。

昨天我請小鷸刷牙的時候，小鷸因為中午看影片所以吃得慢。我請她等會兒補刷。葉宇因此不願意刷牙，他選擇吃四次牙膏。小鷸告訴葉宇 : 「你可以等我一起刷牙。」我當下覺得自己正在被挑戰。我還是在該刷牙的時候自己刷了牙，刷完牙看著他們兩個補刷。小鷸沒有拿著牙刷但她告訴我，她在刷牙。葉宇則跟小鷸炫耀他吃了四次牙膏很厲害。  
於是他們補刷完牙，我又請他們再刷一遍。  
我從他們臉上的表情得知，他們刷得很不甘願。  
於是他們刷完，我請他們泡泡吐掉回位子坐好。  
我問他們

1. 知道自己為什麼被處罰的舉手。 (沒有人舉手)
2. 覺得自己不需要被處罰的舉手。 (也沒有人舉手)
3. 覺得自己應該被處罰，但是很不服氣的舉手。 ( 兩人都舉手了 )

我問葉宇發生什麼事，他覺得自己應該不處罰，但是很不服氣。  
他以為是他刷牙沒刷好，所以被我罰再刷一次。  
我跟他說我其實是罰他該刷牙時不刷，卻不停吃牙膏。  
小鷸覺得自己沒做錯事情。  
我告訴小鷸，在老師請葉宇刷牙的時候，妳告訴葉宇等妳再刷，這樣我會很難管理一個班級。  
小鷸堅持，葉宇不應該聽他的，小鷸責怪葉宇自己沒有判斷能力，不知道自己為什麼要被處罰。  
接下來班上有個停頓，先打破這個停頓的是葉宇。  
葉宇 : 「老師你說完了嗎 ? 老師你說夠了嗎 ?」  
我說 : 「我覺得我沒辦法跟你們溝通，但是我有最後一件事要說。就是我會把你們的狀況如實跟其他學校老師討論，因為如果我沒辦法跟你們好好相處，影響到你們的學習，這會是大家的責任。」  
小鷸聽完之後爆炸了 : 「說啊，你去說啊，說就說啊，頂多就被罵而已，來罵啊。」  
:「我跟其他老師討論這件事情，不是為了讓你被罵，只是我沒辦法跟你們相處，我想知道還有什麼方法可以改變。」  
說完我就離開教室了，去影印下午上課需要的東西。  
因為要記錄班上的情況，所以我這幾次有嘗試在教學卡住或跟學生有衝突時錄音。  
回家我聽我離開教室後了錄音，我聽見小鷸哭了。  
昨天的最後一節課，小鷸不太配合我，一邊跟葉宇說，他下學期要轉學。  
我就出了小日記 – 我下學期要轉學。  
小鷸把題目改成 – 我要換老師。  
接著在課堂上抱怨，寫這個有什麼用，又不會有任何改變。  
:「你如果很討厭一個人，你可以盡到溝通的責任，也許不能換老師，但我會比較知道有什麼可以調整的地方。」  
:「要改變，老師你去死啊，去死，去死，老師去死，不然我去死好了。」小鷸就這樣一邊寫學習單，一邊以我可以聽到的音量抱怨著。

說完這些，在校督導跟我分享了一些跟孩子建立關係的方法。  
包括先釋出我的善意，把自己當演員，嘗試著要笑，主動聊天，找共同話題，創造一件可以一起做的事。  
後來督導好奇我為何會笑不出來。  
Bowen以開玩笑的語氣說 : 「周玟綺人格上有障礙啊，他就有創傷啊。」  
我的在校督導把手放在我的大腿上，她說 : 「我相信，來，你說給我聽。」  
督導要我轉向她好好的說，我沒辦法在學生面前笑的原因。  
我說，其實我不只是在學生面前這樣，原本在大人面前也是這樣，我放不下我身體的警戒。  
然後我就去拿了一大包衛生紙，一邊哭一邊接著說下去 :  
「因為我不是一個可以表達情緒的小孩子，我不被允許難過，也不被允許生氣，所以笑是我的防衛機制。我很愛我的老爸老媽，但我不知道怎麼辦，很多時候我很傷心，但我還是會笑給他們看。但是後來我發現這樣太痛苦了，所以我就選擇不去感覺。我就開始一直打電動，或是一直喝酒，或是一直工作，做一大堆能讓我不去感覺到自己的行為。然後突然有一陣子，我就睡不著覺了，我不睡不著兩個禮拜，然後我就去諮商。在這個過程中，我的諮商師請我想像一個情況，諮商師請我想像有一個小孩子，這個小孩子很努力寫作業，但作業都寫不好，他的媽媽會打他，會把他的作業擦掉請他重寫，這個小孩子還小，他沒辦法反抗他媽媽，所以他只能坐在那，等著這一切過去，比方說等到媽媽想睡覺的時候，這一切就會結束了。他漸漸發現自己可以在天花板上看著自己，想像著被打的這個人不是他自己。因為他實在太痛苦了。這雖然是一個受虐的孩子，但諮商師請我想想，這個例子跟我像不像。然後我知道自己長期解離了。在後續的諮商裡，我盡力去陳述我的感受，諮商師會告訴我，這樣的感覺可能是我難過，或是受傷。然後我才開始找回自己的感覺。所以很多時候，我還是不太知道自己發生什麼事的。我自己印象很深的一次是，我的老師很認真的告訴我們一個他媽媽酒駕載著他老爸的故事，然後自撞電線桿，出了很嚴重的車禍，我居然笑了。老師看著我說:『這不好笑。』那時候我才發現，有時候我笑好像不是真的開心，而是一種防衛機制。太難過，難過到我不想去處理的時候，我就笑。」  
我的督導接著說 : 「聽得出來你的童年受了很嚴重的傷，你把我當成你的家人，如果今天你的家人在這，你想對他們說什麼。」  
我試著說了幾個字，督導請我看著他說話。  
接著我哭了很久很久，說不出半句話。  
督導為了讓我進入情境，模仿著我的家人說著 : 「你今天這個髮型是怎麼了 ?」  
我還是一直哭，想辦法努力的看著他，我說 :「我真的不是故意的，雖然你們可能從來不覺得我棒，我一直沒有辦法符合你們的期待，但是我真的很努力了，雖然我很愛你們。每次回到家聽到你們這樣對我說，我都覺得很不舒服。」  
督導接著說 : 「你不舒服什麼 ?」  
我哭了一陣子接著說 : 「我真的很努力想要減輕家裡的負擔，可是每次當我回到家，我好像都要做好會被傷害的準備，雖然我常常說我工作不忙，壓力不大，每天都很快樂，但是我真的很努力的把我的工作做好，每當我回到家，你們看到我的頭髮就要這樣說，我會感覺自己被責備了。我不知道為什麼你們愛我是看我的外在，我不知道我要用什麼心情回家，我不知道我要不要回家。」  
督導牽著我的手說 : 「原來你一直這麼努力，在這二十幾年的生命裡你承受著這麼多的壓力。你很努力了，我都有看到。」  
然後督導對著我笑著告訴我 : 「你現在是安全的。」  
停頓了一下，他對我說：「你可以不用這麼努力。」  
他問我：「當你聽到我跟你說，你可以不用這麼努力，你有什麼感覺？」  
我說 : 「我不知道要怎麼樣才可以讓事情變好。」  
督導問我 : 「還有嗎 ?」  
我說 : 「我不知道我可不可以做好我的工作。」  
督導 : 「所以你很想做好你的工作嗎 ?」  
我點點頭接著說 : 「我怕，我怕我不夠努力，我不知道我自己還有沒有值得被喜歡的地方。」  
督導 : 「你當然有值得被喜歡的地方啊，我就很喜歡你啊。我是真心的在說這些話的。」  
我點點頭。  
督導讓我哭一陣子，開始考我 5+3 是多少，6x7 ? 5x9 ? 10000+1000 ?  
然後我笑了，督導問我有沒有好點。  
督導跟我說，努力如果是為了別人，很可能把自己的身體搞壞。  
這件事情他也體會了很久很久。他和我分享他教學生涯裡的故事。

接著宜嘉要離開了，我們好好地擁抱了好一陣子。  
督導請我今晚好好放鬆，好好休息，然後張開了手，我們擁抱。

PS 01 : Bowen 在這個對話進行到一半就離開家了。  
PS 02 : 我很謝謝這個場合有宜嘉在。

-

現在回頭看看這段紀錄，知道自己還有許多地方可以處理得更溫柔。  
但也理解過去那一週的我，是很想很想求救的吧。  
我好痛苦，也好想逃走，畢竟這幾週嘗試下來，彷彿所有慣用的、擅長的愛人的方式，都被打回票了。

其實我不太真的清楚，孩子拿起美工刀在我的課堂上劃破自己的課本，跟我有多大的關係。  
我也不太確定孩子說跟我相處一年像是一世紀這麼久，他一個小時也撐不下去，跟我有多少關聯性。

說服自己這些都跟自己沒關係會輕鬆得多。  
當自己要扛起所有的壓力也意外得重。

但無論如何，孩子的情緒反應跟我有多少關係，或大或小都好，  
我能一天一天做到的改變也許就是一天一點。  
也不會因為他超級討厭我，我就改變得更快。

今天去海邊，花了一些時間說服自己活在現在。  
看看眼前的浪，看看粉橘色的天，看看翻湧的雲，和拍打沙岸的浪。  
去享受現在自己在哪，自己正看著怎樣的風景，真的好好地呼吸。  
做一些自己真正喜歡的事情，把美麗的照片分享給自己珍惜的朋友。  
再好好收到大家的愛。

雖然再多人的愛，也沒辦法真正讓我愛我自己，除非我自己想要。  
總之，很感謝提醒我吃飯的朋友，傳給我好多文字擁抱的大夥。

我的心裡還是覺得，是我要面對現在眼前的困難，我必須勇敢，必須足夠強壯。  
但我願意相信當我受傷，當我想逃離自己的時候，你們會心疼我，會擁抱我，會告訴我我已經夠努力了，這些不是我的錯。

就算我知道告訴自己這些是我的責任，但老是要好好照顧自己，其實要耗費好大的力氣，有時候真的只想休息，只想逃避。

就算我要逃，我也知道身旁有你們陪著。  
這樣就夠好了吧。

今天語無倫次的 BLOG 更新就到這吧，我最近真的好累哦。  
是那種累到要找實習週的督導求助，都覺得要把發生的事情用文字好好說清楚，都不想花力氣的累。

對了，跟玫瑰的面談很卡，  
因為我很脆弱，那天我沒有想要解決什麼問題，也沒有想要發展什麼領導力。  
我只想要有人陪我待著，聽我說說話，然後好好回應我，  
也許我就會長出力量，再去面對孩子吧。
